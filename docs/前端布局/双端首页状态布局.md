# 双端首页状态布局

> 本文件只定义页面区域、展示内容与状态切换，不定义颜色、背景、字体、动效或其他视觉样式。参考图仅可参考布局，不可复用其样式。

## 1. 固定页面布局

```text
┌────────────────────────────────────────────────────────────────────┐
│ RustFS 离线同步中心 ｜ Edge 本地节点 / Center 中控端 ｜ 服务状态      │
├───────────────┬────────────────────────────────────────────────────┤
│ 本地 RustFS   │ 运输盘列表                                          │
│ 节点示意区域  │ [硬盘卡片] [硬盘卡片] [硬盘卡片]                     │
│               │ [硬盘卡片] [空槽位]   [空槽位]                       │
├───────────────┴────────────────────────────────────────────────────┤
│ 下方状态区：根据运输盘状态展示系统状态，或当前导出详情              │
└────────────────────────────────────────────────────────────────────┘
```

- 页头固定展示：系统名称、当前端类型、HTTP、本机服务、WebSocket 连接状态。
- 运输盘列表由 WebSocket 全量快照刷新；一张卡片对应一个已发现的运输盘。
- 下方状态区只展示当前选中盘的状态；无盘时展示系统等待状态。
- 本文件的“空槽位”是布局占位，不代表程序要识别物理硬盘槽位。

## 2. 双端共用内容

每张已发现运输盘卡片展示：

| 字段 | 说明 |
|---|---|
| 挂载盘标识 | 例如 `sdb1` |
| 状态 | `READY`、`WRITING` 或 `SEALED` |
| 已占用空间 / 总容量 | 实际文件系统空间 |
| 可写空间 | 实际剩余可写空间 |
| 补充信息 | 按状态展示等待导出、导出中、待导入、导入中或封盘完成 |

空槽位只展示“未插入运输盘”，不展示虚构硬盘信息。

## 3. Edge 状态一：未插入运输盘

```text
运输盘列表：全部为空槽位

下方状态区
  标题：未发现运输盘
  说明：等待插入运输盘
  累计已确认导出对象：N
  累计已确认导出数据量：N
```

没有当前导出文件、速度、当前盘对象数或运输编号。

## 4. Edge 状态二：READY，暂无待导出对象

```text
运输盘列表
  sdb1  READY
  已占用空间 / 总容量
  可写空间
  等待导出

下方状态区
  标题：暂无待导出对象
  当前选择：sdb1、disk_id
  当前盘状态：READY
  累计已确认导出对象：N
  累计已确认导出数据量：N
```

没有当前文件传输进度和速度；运输盘保持 `READY`，不会封盘。

## 5. Edge 状态三：WRITING，正在导出

```text
运输盘列表
  sdb1  WRITING
  已占用空间 / 总容量
  源数据量、可写空间
  正在导出

下方状态区
  累计已确认导出对象：N
  累计已确认导出数据量：N
  当前导出速度：N MB/s

  当前导出：sdb1
  当前文件：来源桶/来源对象路径
  源文件大小：N
  当前文件已传输：N / N
  当前文件进度条

  当前运输盘：disk_id
  当前盘已写入对象 / 源数据量：N / N
  当前盘已占用空间 / 可写空间：N / N
```

- “累计已确认”只统计已封盘并确认导出的历史对象，不包含当前 `WRITING` 盘内数据。
- “当前盘已写入”是当前 `WRITING` 盘的运行中数据，不称为“已确认”。
- Edge 不展示预计完成时间；该字段仅属于 Center 导入任务。

## 6. Edge 状态四：仅有 SEALED 运输盘

```text
运输盘列表
  sdb1  SEALED
  已占用空间 / 总容量
  Edge 编码、已写入对象数
  封盘完成，不可继续写入

下方状态区
  标题：运输盘已封盘
  当前选择：sdb1、disk_id
  当前盘状态：SEALED
  累计已确认导出对象：N
  累计已确认导出数据量：N
```

没有当前文件进度和速度。`SEALED` 盘在 Edge 端只展示，不允许继续写入。

## 7. Center 状态一：未插入运输盘

```text
运输盘列表：全部为空槽位

下方状态区
  标题：未发现运输盘
  说明：等待插入运输盘
  已导入对象总数：N
  已导入源数据总量：N
```

没有当前导入文件、进度、速度和预计完成时间。

## 8. Center 状态二：可初始化运输盘

```text
运输盘列表
  sdb1  未格式化 / 可初始化
  硬盘容量
  当前文件系统（如可读取）

下方状态区
  标题：运输盘需要初始化
  当前选择：sdb1
  操作入口：格式化并初始化，或初始化并注册
```

具体操作由 HTTP 接口触发，不由 WebSocket 触发。非 ext4 的盘显示“格式化并初始化”；已是 ext4、但没有有效 `disk_info.json` 的盘显示“初始化并注册”。

## 9. Center 状态三：SEALED，等待导入

```text
运输盘列表
  sdb1  SEALED
  已占用空间 / 总容量
  来源 Edge 编码、对象数
  等待导入

下方状态区
  标题：等待导入
  当前选择：sdb1、disk_id、来源 Edge
  队列位置
  已导入对象总数：N
  已导入源数据总量：N
```

多个 `SEALED` 盘按 `queued_at` 的先后顺序依次导入。

## 10. Center 状态四：正在导入

```text
下方状态区
  已导入对象总数：N
  已导入源数据总量：N
  当前导入速度：N MB/s
  预计完成时间：时间

  当前导入：sdb1
  当前文件：来源桶/来源对象路径
  解压后源文件大小：N
  当前文件已传输：N / N
  当前文件进度条

  当前运输盘：disk_id、来源 Edge 编码
  当前盘已处理对象 / 源数据量：N / N
```

Center 的“已导入总数、已导入总数据量”按解压后源文件大小统计；预计完成时间只在 Center 导入中展示。
