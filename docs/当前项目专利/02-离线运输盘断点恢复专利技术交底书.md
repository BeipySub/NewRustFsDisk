# 离线运输盘断点恢复专利技术交底书

> 定位：备选专利。该机制已作为主案的实施方式披露；完成查新后，确认其具有独立创新点时再单独申请。

## 1. 发明名称

一种基于盘内文件与导出账本对账的离线数据恢复方法、系统、设备及存储介质。

## 2. 要解决的问题

运输盘在写入过程中可能被拔出、掉电或发生程序异常。此时盘内文件与 Edge 本地记录可能不一致：盘上可能有未记录的文件，账本也可能记录了实际不存在的文件。直接继续写入会造成重复、遗漏或错误封盘。

## 3. 方案说明

Edge 发现状态为 `WRITING` 且来源站点与本机一致的运输盘时，读取该盘 `disk_id` 对应的运行时导出账本，并扫描盘内对象 ZIP 文件。

系统逐项对比盘内 ZIP 和账本记录：盘内存在但账本没有记录的 ZIP 被删除；账本存在但盘内没有对应 ZIP 的记录被删除。对账完成后，仅保留同时存在于盘内和账本中的已完成对象。

系统继续扫描来源对象存储，跳过已确认导出对象和当前运输盘中仍有效的运行时记录；其余对象按照正常写盘流程重新写入。恢复完成后，仍按封盘条件生成清单并更新为 `SEALED`。

## 4. 关键技术特征

1. 使用运输盘 `disk_id` 关联盘内数据和 Edge 本地运行时导出账本。
2. 在恢复前扫描盘内正式 ZIP 文件，并与账本进行双向对账。
3. 盘内多出的 ZIP 文件和账本中缺失对应 ZIP 的记录分别清除。
4. 对账后从保留的有效记录继续导出，而不是重新复制整块运输盘的数据。

## 5. 技术效果

- 拔盘或异常后可恢复到可确认的数据状态。
- 避免把不完整文件写入封盘清单。
- 减少重复复制已成功写入对象所产生的磁盘 I/O 和时间。

## 6. 可选实施方式

- 对账时可进一步校验 ZIP 文件大小、摘要或文件名与账本字段是否一致。
- 盘内异常文件可删除、移动到隔离目录或标记为待人工处理。
- 账本可以保存在本地数据库或可靠的本地文件中。
